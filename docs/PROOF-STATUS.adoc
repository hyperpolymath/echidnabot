== Evidence rules

Updated 2026-11-01 on `arena/68c18146-echidnabot`, based on
`ab26bd54c8bdc04da8cc48c0778a25eb774be268`. New files are working-tree
candidates, not committed or checked proof receipts. No Grade 3 attainment
is claimed. `open` means not checked/done, `argued` means an explicit
assumption, and `tested-only` requires an actual observed bounded check.
ConfidenceLevel::Level3 is a runtime heuristic, NOT Mathesis Grade 3.

Policies and pinned references are in
link:ESTATE-ROUTING-AUDIT.adoc[the routing audit]. Theory requires strict
Agda checks, with separately recorded Rocq/Lean statement correspondence and
kernel results. Rust behaviour requires Creusot on actual first-party code;
a mathematical model does not establish runtime refinement.

== Pre-existing proof material and semantic reconstruction

The old `proofs/ECHO-TYPES-AUDIT.adoc` classified the four Lean/Coq files
as prover fixtures. That remains true. Its statement that ABI scaffolding
is out of scope does NOT make that scaffolding verified.

* `proofs/coq/trivial_ok.v`: `forall (A : Prop), A -> A`.
* `proofs/lean/trivial_ok.lean`: `(A : Prop) -> A -> A`.
* New `proofs/agda/FixtureIdentity.agda`: `(A : Set) -> A -> A`.
  This is a semantic reconstruction of the constructive identity schema,
  because there was no Agda record. It is not witness transport. Rocq/Lean
  Prop and Agda Set differ; correspondence is limited to propositional
  identity and remains `open` until checked and justified explicitly.
  All three current executions are unavailable in this sandbox.
* `proofs/coq/admitted_stub.v` and `proofs/lean/sorry_stub.lean` are negative
  fixtures, not candidate proofs. Their escape hatches must stay intact.
  They are excluded from Grade 3 counts, not repaired into passing fixtures.
* JSON files under `proofs/test_fixtures` are webhook/prover inputs, not proofs.

=== ABI scaffold debt (not verified)

`src/abi/{Types,Layout,Foreign}.idr` contains literal `{{PROJECT}}` module
names, unresolved holes and placeholder foreign symbols. These are templates,
not an instantiated echidnabot ABI. `HasSize`/`HasAlignment` have unrestricted
constructors and therefore do not establish actual compiler layout.
`exampleStructSize` claims 16 while its own comment describes 24 bytes.
`offsetInBounds` quantifies over arbitrary Field values without membership or
bounds premises, so it cannot be proved as written. Layout checking and
foreign pointer/lifetime obligations also remain unresolved.

Status: `open`. Do not replace holes with postulates or transcribe these
claims to Agda as if they were true. A semantic rewrite needs the actual
exported ABI, supported targets, field representations, ownership and bounds
premises; the Rust interface proof policy remains active. No new ABI symbols
or layout contracts are invented in this patch.
